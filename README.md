# Deadpan Forecasts

One line, at most 160 characters: a deadpan TV-meteorologist weather forecast for a city that does not exist, written for the make.fun bounty "Deadpan Forecasts for Cities That Do Not Exist".

> Cloudy in Brindlewick tonight with a high of 17, light winds, and one cloud that has been following the postman since Tuesday. It seems personal.
